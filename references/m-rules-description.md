## M39

**DESCRIPTION FORMAT — HOOK → BULLETS → CAVEAT → CTA → SOURCES → 3 HASHTAGS** (added 2026-11-16, from deep research on YouTube Shorts description best practice + Saad's order "next videos mei is chz ko permanent ker do, description ko upgrade rakhna hamesha"): every Joker Short description follows this order, never a single-paragraph wall of text.

Why: the Shorts feed shows NO description text at all (verified live Nov 16 — player shows channel, title, sound only), so the description's job is search relevance + credibility for the minority who expand it. A long description does not hurt feed discovery (no evidence either way); a wall of text earns nothing because nobody expands it.

Order:
1. **Hook** — one sentence, GTA VI + the news noun, ≤120 characters, keyword-first. No blank line after line 1 (a blank line wastes a whole row of the preview box).
2. **Restating sentence** — the news in full, with the main keyword again, in the words a searcher would type.
3. **Fact bullets** — 2–4, with `- ` (YouTube's bullet format), each with attribution in-line ("X reports…").
4. **Unknown / caveat paragraph** — what is not yet known, stated plainly, one sentence. For a news channel this is a trust signal.
5. **Countdown + CTA** — countdown line re-derived from the ACTUAL air date per M30, then "Subscribe for more GTA VI news."
6. **Sources line** — outlet names + dates, verbatim (`Sources: Outlet (Date); …`). No bare URLs: Shorts description URLs are non-clickable per YouTube Help, so a URL adds nothing a source name does not.
7. **Exactly 3 hashtags, same 3 every time** — `#GTA6 #GTAVI #GamingNews`. YouTube shows at most 3 by the title; above 60 all hashtags are ignored.

Rules: unique description per Short (never reuse yesterday's text); no keyword list, no tag pile, no product links; length as short as the facts allow, never above ~1,000 characters; preview the description in search, on the watch page and on a phone before publishing, as YouTube recommends.

Copy-paste skeleton (replace bracketed parts only; delete lines that do not apply — never invent a line to fill one):

```
[Hook: GTA VI + the one news fact, one sentence, under 120 characters.]
[One sentence restating the news in full, with the main keyword again.]
- [Fact 1: figure + attribution]
- [Fact 2: figure + attribution]
- [Fact 3: figure + attribution]
- [Fact 4 if needed — max 4 bullets]

[What is still unknown / the honest caveat, one sentence. If nothing is unknown, delete this paragraph.]

[Countdown if it is a series line, e.g. "Three days to launch."] Subscribe for more GTA VI news.

Sources: [outlet (date)]; [outlet via outlet (date)]; …

#GTA6 #GTAVI #GamingNews
```
