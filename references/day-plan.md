# Day plan — launch window (what do I do tonight?)

For the GTA VI launch week (Nov 16–22, 2026). One night, one video, no guessing.

## Tonight (one video)

1. Pick the topic from the news (one fresh official peg — Rockstar post, store page,
   or official trailer frame). Write the ledger (≥3 sources) and the banned list.
2. Hook shortlist: 5–12 candidates, score them, pick one (human pick).
3. ChatGPT brief → script + SEO + thumbnail brief. Hand-count the script (both counts).
4. Pool gate (M20). If STOP, pick a different topic — do not build on an unproven pool.
5. VO → STT → concat → stills/motion → cards → captions → mix.
6. Preview-first: first 10s + every card still, checked. Then the full render (crf 12).
7. Fix → grade → re-measure. Builder QC. Red-team gate. Schedule (M30 re-derived).
8. Log the result; set the 48h retention read.
